File Organizer

Overview

The File Organizer is a simple Python application that automatically sorts files into folders based on their file extensions. It scans a selected folder, creates folders when needed, moves files to the correct location, and safely renames duplicate files.

Technologies Used

Python, pathlib, shutil

## How to Run

Place your files inside the TestFolder directory.

Open a terminal in the project folder.

Run:
python FileOrganizer.py
